Fire sprinkler design software

Imbercast

3D sprinkler design and hydraulic calculation.

A standalone desktop application for laying out fire sprinkler systems in three dimensions and calculating them to NFPA 13. Import the floor plan, draw the system, run the calc, print the package. No CAD license required.

What it does

01

One 3D model

Geometry, elevations and hydraulics live in the same model, so there is no separate schematic to keep in sync.

02

Hydraulic engine

Hazen-Williams nodal analysis across trees, grids and loops, residential through commercial, with automatic peaking.

03

Import and draw

Bring in a DXF or PDF floor plan and lay the system out directly over it. AutoCAD is not part of the workflow.

04

Calc package

Results output with plan and isometric figures generated from the model, ready to drop into a submittal.
